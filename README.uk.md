# Джарвіс

[English](README.md) | [Українська](README.uk.md)

**100% приватний AI-голосовий асистент, який живе на твоєму комп'ютері** (працює офлайн). Говори природно, наче Джарвіс це третя людина в кімнаті: скажи його ім'я будь-де в реченні й отримай розмовну відповідь з урахуванням контексту. Він пам'ятає все, завжди знає поточне розташування і час, уміє шукати в інтернеті, читати екран, керувати Chrome, рахувати харчування та багато іншого, з підтримкою необмеженої кількості MCP та інструментів без деградації контексту. Чутливу інформацію автоматично вилучають перед записом на диск.

🔒 100% локальна обробка. Жодних підписок. Жодного збору даних. Автоматичне вилучення чутливої інформації. Безкоштовне офлайн-диктування в комплекті.

> 🇺🇦 **Український білд** (цей форк): весь голосовий конвеєр, десктопний UI, майстер налаштувань і шар LLM-промптів локалізовано українською (неформальне «ти»). Чат налаштовано на `qwen2.5:7b-instruct` для GPU з 8 ГБ VRAM, Whisper `medium` на CPU, український голос Piper, wake-слово «джарвіс», плюс додаткові вбудовані інструменти: `launchApp` (запуск програм, ігор, YouTube, Steam чи Spotify за нечітко зіставленими українськими псевдонімами), `askAi` (передати питання іншій локально встановленій моделі Ollama), `timerTool` (таймери з укр-парсингом тривалості й голосовими оголошеннями), `systemStats` (живий стан CPU, RAM, диска, батареї та GPU), `mediaControl` (пауза, гучність і перемотка системними медіа-клавішами), `notesTool` (голосові нотатки, списки задач і покупок, усе локально) та `personaTool` (твоє ім'я, звертання й вподобайки, які Джарвіс враховує в кожній відповіді). Ігровий режим вивантажує LLM з VRAM, поки запущена гра. Після кожної відповіді Джарвіс ще 15 секунд (налаштовується) слухає продовження без повторного wake-слова. У вікні налаштувань є редактор тем з колір-піками та локальними пресетами користувача.

## Чому Джарвіс?

**🔒 Твої дані залишаються твоїми** - 100% локальна AI-обробка. Без хмари, без підписок, без збору даних. Автоматичне вилучення чутливої інформації. Це принципово.

**🗣️ Третя людина в кімнаті** - На відміну від голосових асистентів, що відповідають лише на жорсткі команди, Джарвіс розуміє розмови. Він тримає короткий тимчасовий контекст того, що обговорюється, тож коли ти питаєш «Джарвіс, а ти як гадаєш?», він точно знає, про що йдеться. Хай встряє в розмову з друзями, допомагає налагоджувати код, поки ти промовляєш проблему, або зважує рішення.

**🧠 Ніколи не забуває** - Необмежена пам'ять між розмовами. Пристосовує тон до теми. З часом вивчає твої уподобання.

**🎙️ Безкоштовне диктування** - Затисни гарячу клавішу, промов, відпусти, і твої слова з'являться текстом у будь-якому застосунку. Як WisprFlow, але безкоштовно, офлайн і приватно. Без підписки, без хмарної транскрипції.

**🔌 Розширюваність** - Інтеграція MCP з'єднує Джарвіса з тисячами інструментів: розумний дім, GitHub, Slack, бази даних тощо. Розумний вибір інструментів означає, що додання нових інструментів нічого не сповільнює.

**📊 Прозорий прогрес** - Ми відстежуємо, що працює (а що ні), автоматичними оцінками. [Поточна точність →](EVALS.md)

**🚧 Відомі обмеження:** Джарвіс перебуває в активній розробці. Основна розробка йде на macOS. Підтримка Windows/Linux може відставати. Ми будуємо відкрито, [issues](https://github.com/isair/jarvis/issues) та [внески](https://github.com/isair/jarvis/pulls) вітаються!
- Поки що лише голос, без текстового чату ([#35](https://github.com/isair/jarvis/issues/35))
- Немає мобільних застосунків ([#17](https://github.com/isair/jarvis/issues/17))
- Команди «стоп» під час мовлення іноді фільтруються як відлуння ([#24](https://github.com/isair/jarvis/issues/24))
- Диктування недоступне на macOS 26+ (Tahoe) через несумісність pynput ([#172](https://github.com/isair/jarvis/issues/172))

## Можливості

- **Розуміння розмови** - Розуміє поточні дискусії. Питай «Джарвіс, а ти як гадаєш?», і він знає, про що йдеться. Природно працює в розмовах кількох людей.
- **Необмежена пам'ять** - Ніколи не забуває. Шукає по всій історії твоїх розмов. Додано GUI Переглядача пам'яті.
- **Адаптивний тон** - Автоматично точний для коду, прагматичний для бізнесу, підбадьорливий для добробуту, без ручного переключення режимів
- **Розумний вибір інструментів** - Фільтрування релевантності на основі ембедингів обирає лише потрібні для запиту інструменти: додавай необмежену кількість MCP-інструментів без деградації швидкодії
- **Вбудовані інструменти** - OCR зі скріншотів, вебпошук (резервний ланцюг DuckDuckGo → Brave → Wikipedia з автоматичним завантаженням сторінок), погода, доступ до файлів, відстеження харчування, обізнаність у розташуванні, запуск застосунків з налаштовуваного каталогу, передача питань іншим локально встановленим AI-моделям, плюс «аварійний вихід» для пошуку інструментів, яким агент користується, щоб розширити власний набір посеред відповіді
- **Пам'ять-граф знань** - Самоорганізована пам'ять, що вчиться з розмов, автоматично поділяється за темами і автоматично витягує релевантні знання
- **Природний голос** - Скажи «Джарвіс» будь-де в реченні, перебий словом «стоп», став продовжуй без повторення wake-слова
- **Режим диктування** - Безкоштовна офлайн-альтернатива WisprFlow: затисни гарячу клавішу, промов, відпусти, щоб вставити текст у будь-який застосунок
- **Інтеграція MCP** - Підключення до тисяч зовнішніх інструментів (Home Assistant, GitHub, Slack тощо)

## Системні вимоги

| Залізо | VRAM | Модель |
|----------|------|-------|
| Більшість користувачів | 8GB+ | `gemma4:e2b` (типова) |
| Краща якість | 16GB+ | `gemma4:e4b` |
| Високопродуктивне | 24GB+ | `gpt-oss:20b` |

> **Примітка:** вимоги до VRAM включають модель судді намірів (`gemma4:e2b`), яка завжди завантажена поруч із чат-моделлю для класифікації голосових намірів. Типова модель збігається з нею, тож додаткової VRAM не потрібно.

Майстер налаштувань проведе тебе крізь вибір і встановлення моделі під час першого запуску.

> 🇺🇦 **Український білд:** цей білд постачається налаштованим на `qwen2.5:7b-instruct` для GPU з 8 ГБ VRAM (Whisper `medium` на CPU). Повну картину дивись у блоці 🇺🇦 на початку [англійського README](README.md).

<details>
<summary><strong>Провайдер LLM (Ollama або OpenAI-сумісний)</strong></summary>

Типово Джарвіс запускає все локально через [Ollama](https://ollama.com): без API-ключів, нічого не залишає твоєї машини. Якщо ти вже маєш OpenAI-сумісний сервер (**LM Studio**, **oMLX**, `llama-server` зі **llama.cpp**, **vLLM**, **LocalAI**...), можеш націлити Джарвіса на нього. Твої дані так само подорожують лише до серверів, якими керуєш ти.

Обери провайдера на першому кроці Майстра налаштувань або в **⚙️ Settings → 🔌 LLM Provider**. Без редагування JSON. Для довідки, основні ключі:

```json
{
  "llm_provider": "openai_compatible",
  "llm_base_url": "http://localhost:1234/v1",
  "llm_api_key": "",
  "llm_chat_model": "your-served-model-name"
}
```

- `llm_base_url`: базова URL-адреса OpenAI API твого сервера (типова для LM Studio: `http://localhost:1234/v1`).
- `llm_api_key`: лише якщо твій сервер її вимагає; інакше залиш порожнім.
- `llm_chat_model`: будь-яка назва моделі, яку віддає твій сервер.

**Ембединги** (потрібні для пошуку пам'яті) можуть працювати на іншому бекенді. Якщо чат-сервер не має ендпоінта ембедингів, залиш модель ембедингів порожньою, щоб повернутися до Ollama, або явно скеруй ембединги:

```json
{
  "embedding_provider": "ollama",
  "embedding_model": "nomic-embed-text"
}
```

Залиш `embedding_provider` порожнім, щоб використовувати той самий провайдер, що й для чату. Коли модель ембедингів недоступна, пошук пам'яті плавно деградує до пошуку за ключовими словами.

</details>

<details>
<summary><strong>Розпізнавання мовлення (Whisper)</strong></summary>

#### Режими мови
- **Багатомовний** (типовий, 99 мов): `"whisper_model": "medium"`
- **Лише англійська** (трохи краща точність для англійської): `"whisper_model": "medium.en"`

#### Розміри моделей
| Модель | Англійська | Багатомовна | Завантаження | VRAM | Швидкість |
|-------|---------|--------------|----------|------|-------|
| Tiny | `tiny.en` | `tiny` | ~75 МБ | ~1 ГБ | ~10x |
| Base | `base.en` | `base` | ~140 МБ | ~1 ГБ | ~7x |
| Small | `small.en` | `small` | ~465 МБ | ~2 ГБ | ~4x |
| **Medium** | `medium.en` | `medium` | ~1,5 ГБ | ~5 ГБ | ~2x |
| Large V3 Turbo | - | `large-v3-turbo` | ~1,5 ГБ | ~6 ГБ | ~8x |

Швидкість відносна до початкової великої моделі. [Джерело](https://github.com/openai/whisper)

#### GPU-акселерація (Windows)
Якщо маєш NVIDIA GPU, Джарвіс може використовувати CUDA для значно швидшого розпізнавання мовлення. Інсталятор Windows пропонує необов'язкове завантаження CUDA під час налаштування. Для розробки:
```bash
pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
```
CUDA виявляється автоматично: конфігурація не потрібна.

#### Фільтри галюцинацій
Whisper іноді видає впевнені, але хибні транскрипції під час тиші або фонового шуму (наприклад, інтро новинних шоу, музика). Два пороги відфільтровують їх до того, як вони дістануть судді намірів:

- `"whisper_min_confidence": 0.3` відкидає сегменти, чия впевненість, похідна від `avg_logprob`, падає нижче цього значення. Підвищи, якщо бачиш шум низької впевненості, що просочується; знизь, якщо відкидається справжнє мовлення.
- `"whisper_no_speech_threshold": 0.5` відкидає будь-який сегмент, чий `no_speech_prob` дорівнює або перевищує це значення, незалежно від `avg_logprob`. Ловить випадок, коли Whisper упевнений у вигаданій фразі, але його власний сигнал відсутності мовлення каже, що аудіо було тихим. Застосовується до обох бекендів: faster-whisper та MLX.

Обидва пороги доступні у вікні Settings у розділі *Whisper*.

</details>

<details>
<summary><strong>Голосовий інтерфейс (розширене)</strong></summary>

**LLM-суддя намірів** - Джарвіс використовує `gemma4:e2b` для інтелектуальної класифікації голосових намірів (виявлення відлуння, витяг запиту, команди зупинки). Ця модель автоматично встановлюється поруч із обраною чат-моделлю під час налаштування. Суддю намірів не можна вимкнути, але він плавно повертається до простішого текстового зіставлення, якщо Ollama недоступна.

**Маршрутизатор інструментів** - Коли `"tool_selection_strategy": "llm"` (типове), Джарвіс просить малу LLM обрати, які інструменти релевантні для кожного запиту, скорочуючи каталог інструментів, який бачить чат-модель. Типово цей виклик маршрутизації повторно використовує модель судді намірів: вона вже розігріта і досить мала, щоб не гальмувати хід. Перевизнач через `"tool_router_model": "<name>"`, щоб присвятити маршрутизації іншу модель. Інші стратегії: `"keyword"` (швидко, без LLM), `"embedding"` (nomic-embed-text), `"all"` (без фільтрування).

**Планувальник списку задач** - Перед агентним циклом Джарвіс виконує короткий прохід планування, що розкладає багатокрокові запити на впорядкований список підзадач. Для малих моделей (класу `gemma4:e2b`) кожен запланований крок безпосередньо розв'язується в конкретний виклик інструменту, без покладання на чат-модель для перепланування крок за кроком. Це суттєво покращує надійність багатокрокових задач. Опції конфігурації:

```json
{
  "planner_enabled": true,          // set to false to disable the planner entirely
  "planner_model": "",              // override which model plans (default: reuses tool_router_model chain)
  "planner_timeout_sec": 6.0        // per-call timeout for plan and step-resolver LLM calls
}
```

</details>

<details>
<summary><strong>Проходи стиснення для малих моделей (розширені)</strong></summary>

Малі чат-моделі (~2B, наприклад `gemma4:e2b`) різко деградують зі зростанням промпту. Джарвіс виконує два дешеві дистиляційні проходи, щоб тримати промпт стислим:

- **Стиснення пам'яті**: згортає записник і відкликання графа в коротку примітку, відфільтровану за релевантністю, перед вставленням як фоновий контекст.
- **Стиснення результатів інструментів**: згортає сирий payload інструменту (особливо блоки UNTRUSTED WEB EXTRACT з webSearch) у коротку примітку з атрибуцією джерела перед тим, як вона дістане основній моделі відповіді.

Обидва проходи автоматично вмикаються для малих моделей (≤7B) і лишаються вимкненими для великих. Для малих моделей стиснення результатів інструментів також запобігає роздуванню контекстного вікна великими payload'ами fetch_web_page. Перевизнач у `~/.config/jarvis/config.json`:

```json
{
  "memory_digest_enabled": null,          // null = auto-on for SMALL, false to force off, true to force on
  "tool_result_digest_enabled": null,     // null = auto-on for SMALL, false to force off, true to force on
  "llm_digest_timeout_sec": 8.0           // tight ceiling shared by both passes
}
```

Живі логи показують рядки `🧩 Memory digest: …` і `🧩 Tool digest: …`, коли прохід виконався, тож видно, коли підкладку було замінено.

</details>

## Режим диктування: безкоштовна альтернатива WisprFlow

Затисни гарячу клавішу для запису мовлення, відпусти, щоб вставити транскрипцію в будь-який застосунок. Працює всюди: редактор, браузер, чат, термінал. Повністю локально, повністю безкоштовно.

<p align="center">
  <img src="docs/img/dictation-history.png" alt="Історія диктування" width="400">
  <img src="docs/img/setup-wizard-dictation.png" alt="Майстер налаштувань: диктування" width="400">
</p>

| Платформа | Типова гаряча клавіша |
|----------|---------------|
| **Windows** | Ctrl + Win |
| **macOS** | Ctrl + Option |
| **Linux** | Ctrl + Alt |

- 🔒 **100% офлайн**: твоє мовлення ніколи не залишає твою машину (на відміну від хмарних сервісів диктування)
- 🧠 **Спільна модель Whisper**: використовує те саме розпізнавання мовлення, що й голосовий ввід, без додаткової пам'яті
- ⚡ **Нульова затримка запуску**: без обходу сервера, транскрипція починається в мить відпускання
- 📋 **Універсальне вставлення**: працює в будь-якому застосунку, що приймає `Ctrl+V` / `Cmd+V`
- 🔇 **Не нав'язливий**: головний голосовий слухач автоматично призупиняється під час диктування
- ✋ **Режим без рук**: подвійне натискання гарячої клавіші тримає запис без утримання; натисни знову або Escape, щоб зупинити
- 🧹 **Вилучення слів-паразитів**: необов'язкове очищення на основі LLM прибирає «ем», «е-е», «ну», «ти знаєш», зберігаючи зміст
- 📖 **Власний словник**: визнач заміни `"неправильно -> правильно"` для жаргону, імен і технічних термінів
- 📜 **Вікно історії**: переглядай, копіюй або видаляй минулі диктування з системного трея
- 🎛️ **Легке налаштування**: сконфігуруй диктування в майстрі налаштувань або будь-коли в Settings (випадальний список гарячої клавіші, перемикач вилучення паразитів, редактор власного словника)

Налаштуй гарячу клавішу в Settings або `config.json`:
```json
{
  "dictation_hotkey": "ctrl+alt",
  "dictation_filler_removal": true,
  "dictation_custom_dictionary": [
    "jarvis -> Jarvis",
    "pytorch -> PyTorch"
  ]
}
```

> **Примітка:** macOS вимагає дозволів Accessibility для глобальної гарячої клавіші. Linux вимагає X11 (обмежена підтримка Wayland).

<details>
<summary><strong>Синтез мовлення</strong></summary>

**Piper TTS (типовий)**: нейронний TTS, що автоматично завантажується при першому використанні (~60 МБ):
- Працює з коробки: налаштування не потрібні
- Якісний британський англійський чоловічий голос (en_GB-alan-medium)
- Швидкий локальний синтез із точним відстеженням тривалості

Щоб використати інші голоси Piper, завантаж їх із [HuggingFace](https://huggingface.co/rhasspy/piper-voices) і встанов:
```json
{
  "tts_piper_model_path": "~/.local/share/jarvis/models/piper/en_GB-alan-medium.onnx"
}
```

**Джарвіс відповідає мовою встановленого голосу.** Piper постачає голоси для 40+ мов, і голос може вимовляти лише свою мову. Націль `tts_piper_model_path` на, скажімо, `uk_UA-ukrainian_tts-medium.onnx`, і Джарвіс і відповідатиме, і говоритиме українською. Завантаж `.onnx` і його sidecar `.onnx.json` разом: саме sidecar підказує Джарвісoві, якою мовою говорить голос. Типовий голос британська англійська, тож недоторкане встановлення не змінюється.

**Chatterbox**: AI-голос з керуванням емоціями (потребує запуску з джерел):
```json
{ "tts_engine": "chatterbox" }
```

Клонування голосу з Chatterbox: додай зразок .wav на 3-10 секунд:
```json
{
  "tts_engine": "chatterbox",
  "tts_chatterbox_audio_prompt": "/path/to/voice.wav"
}
```

</details>

<details>
<summary><strong>Визначення розташування</strong></summary>

Джарвіс може давати відповіді з урахуванням розташування (погода, локальний час тощо), використовуючи локальну базу GeoLite2: хмарні сервіси геолокації не використовуються.

**Ланцюг виявлення IP** (за порядком переваги):
1. **Ручний IP**: сконфігуруй `location_ip_address` у налаштуваннях
2. **UPnP**: запитує твій локальний роутер (трафік не лишає LAN)
3. **Евристика сокета**: визначає, який інтерфейс маршрутизує назовні (нічого не надсилається)
4. **DNS-запит OpenDNS**: одиночний запит `myip.opendns.com` до `208.67.222.222` (єдиний зовнішній запит)

Якщо твій провайдер використовує carrier-grade NAT (CGNAT), Джарвіс автоматично визначає твій справжній публічний IP через той самий DNS-запит OpenDNS. Це можна вимкнути:

```json
{
  "location_cgnat_resolve_public_ip": false
}
```

**Налаштування:** Зареєструй безкоштовний акаунт [MaxMind GeoLite2](https://www.maxmind.com/en/geolite2/signup), завантаж базу City (формат MMDB) і збережи до `~/.local/share/jarvis/geoip/GeoLite2-City.mmdb`. Майстер налаштувань проведе тебе крізь це.

</details>

## MCP-інтеграції

> **Персистентність сесій:** кожен MCP-сервер запускається один раз, і його stdio-сесія лишається відкритою між викликами інструментів. Сервери зі станом (наприклад, автоматизація браузера, де сервер володіє довгоживучим процесом Chrome) працюють коректно. Якщо маєш сервер, який волів би не тримати резидентним, встанови `"idle_timeout_sec": 300` у його записі конфігурації, і Джарвіс звільнить його після стількох секунд без активності.

## Усунення несправностей

<details>
<summary><strong>Поширені проблеми</strong></summary>

**Перший запуск трохи триває**: Джарвіс прогріває моделі Whisper, чат і суддю намірів перед оголошенням «Listening!», тож перша взаємодія здається миттєвою. Це додає кілька секунд на холодному старті й обмежене 60 с: якщо Ollama повільна, Джарвіс все одно почне слухати і завантажить моделі на вимогу.

**Джарвіс мене не чує**: перевір дозволи мікрофона, говори чітко після «Джарвіс»

**Відповіді повільні**: переконайся, що маєш достатньо VRAM (8GB+ для типової моделі; інші моделі дивись у Системних вимогах)

**Windows: застосунок не запускається**: спочатку розпакуй zip повністю, перевір Windows Defender

**macOS: «Застосунок неможливо відкрити»**: правий клік → Open, або System Settings → Privacy & Security → Allow

**Linux: немає іконки трея**: `sudo apt install libayatana-appindicator3-1`

**Джарвіс постійно ухиляється від питань, на які вже відповідав**: малі моделі можуть записувати власні минулі невдачі до записника, що потім наштовхує майбутні сесії повторювати їх. Нові записи автоматично очищаються; щоб прибрати історичні записи, відкрий Переглядач пам'яті, перейди на вкладку Diary і натисни **Clean up deflection narration** у секції Maintenance на бічній панелі. Вилучаються лише речення, що оповідають про невдачі асистента; решта кожного запису лишається.

</details>

## Для розробників

<details>
<summary><strong>Запуск з джерел</strong></summary>

```bash
git clone https://github.com/isair/jarvis.git
cd jarvis

# macOS
bash scripts/run_macos.sh

# Windows (з Micromamba)
pwsh -ExecutionPolicy Bypass -File scripts\run_windows.ps1

# Linux
bash scripts/run_linux.sh
```

Запуск з джерел умикає Chatterbox TTS (AI-голос з емоціями та клонуванням). Piper TTS працює і в bundled-режимі, і з джерел.

</details>

<details>
<summary><strong>Захист приватності</strong> (залишись 100% офлайн)</summary>

```json
{
  "web_search_enabled": false,
  "wikipedia_fallback_enabled": false,
  "brave_search_api_key": "",
  "mcps": {},
  "location_auto_detect": false,
  "location_cgnat_resolve_public_ip": false,
  "location_enabled": false
}
```

Перевірка: `sudo lsof -i -n -P | grep jarvis` (має показувати лише 127.0.0.1 до Ollama)

</details>

<details>
<summary><strong>Резервний ланцюг вебпошуку</strong></summary>

Коли DuckDuckGo обмежений за частотою або не повертає нічого придатного для завантаження, Джарвіс проходить малий резервний ланцюг перед тим, як здатися, замість вигадування:

1. **Brave Search**: за вибором, потребує `brave_search_api_key`. Безкоштовний тариф: 2 000 запитів на місяць. Отримай ключ на [api.search.brave.com](https://api.search.brave.com/app/keys).
2. **Wikipedia**: нуль налаштувань, типово увімкнено, використовує хост Wikipedia, що відповідає мові, яку Whisper автоматично визначив у вислові (тож турецьке питання отримує турецьку відповідь). Вимкни через `wikipedia_fallback_enabled: false`.
3. **Чесна відмова**: якщо всі провайдери зазнають невдачі, відповідь каже, що пошук був заблокований, замість щось видумувати.

Весь ланцюг обмежений дедлайном ~20 с за настінним годинником, тож завислий провайдер не може вибрати весь бюджет затримки голосового асистента.

</details>

## Приватність і зберігання

- **100% офлайн**: хмарні сервіси не потрібні
- **Авто-вилучення**: електронні адреси, токени, паролі автоматично вилучаються
